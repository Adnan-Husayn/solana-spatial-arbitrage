How to read this

Spread
The gap between the two spot prices. It is gross: no fees are taken out.
Fee hurdle
What a round trip pays the two pools: Raydium's 0.25% plus Orca's fee tier. A spread below it cannot profit at any size.
Net result
Also subtracts a 10,000 lamport Jito tip and a 25,000 lamport transaction fee, and accounts for price impact.
Limits
Orca quotes are only trusted inside the pool's current tick range. Raydium's price uses vault balances, which sit slightly off its true reserves.
Data
Polled from a public RPC every few seconds. A real bot sees updates sooner and still loses most races on this pair.
RPC endpoint

Leave empty to use the built-in public endpoints. A custom URL is stored only in this browser.
